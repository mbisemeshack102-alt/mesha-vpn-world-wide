Jinsi ya kujaribu kwa simu mbili

  1. Washa Mobile Data kwenye simu ya kwanza.
  2. Washa Personal Hotspot kwenye simu hiyo.
  3. Unganisha simu ya pili kwenye WiFi ya hotspot.
  4. Fungua anwani hii hii kwenye simu ya pili, kisha bonyeza “Jaribu tena”.
  5. Ikiwa intaneti na API vinafikiwa, hatua ya majaribio ya akaunti/dashboard inaweza kuendelea.

Kama API bado haijawekwa kwenye server ya umma, jaribio la API litaonyesha halijafikiwa hata kama hotspot ina intaneti.

Kinachohitajika kwa mtu aliye mbali

Hotspot ya simu haiwezi kufikiwa moja kwa moja na mtu aliye mbali. Muunganisho wa WireGuard wa mbali unahitaji VPS au server yenye anwani inayofikika, kisha peer za WireGuard zisanidiwe. Usitume password, private key au QR yenye siri kwa mtu mwingine.
